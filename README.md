# YouDown Simple v1.0

Versi sederhana sesuai konsep:
- satu halaman
- Welcome + panah
- Paste link + Render
- Preview
- Video 144p–1080p
- Audio 128–320 kbps
- Download
- Hasil download langsung di halaman yang sama
- Player audio/video
- Menu titik tiga: Bagikan/Hapus
- Theme hitam/putih
- About
- Setting Indonesia/English

## Menjalankan
1. Install Node.js LTS.
2. Install `yt-dlp` dan `ffmpeg` dan pastikan keduanya ada di PATH.
3. Jalankan:
   npm install
   npm start
4. Buka http://localhost:3000

Gunakan hanya untuk konten yang Anda berhak unduh dan sesuai aturan platform. Implementasi ini tidak melakukan bypass DRM, login, paywall, atau private content.
